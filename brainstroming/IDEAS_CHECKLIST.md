## Abhi baqi / advanced kaam

- [ ] Custom layer membership, building subcategories and more shared style controls.
- [ ] Explicit utility nodes and links: source, tank/pump, transformer, meter and consumer connections.
- [ ] Ten-house water/electricity demonstration, source tracing and estimated capacity checks.
- [ ] Physical pipe depths, underground/section views and service clash detection.
- [ ] Failure isolation and affected-consumer reports. [Full plan](../docs/GIS_LAYERS_AND_NETWORKS_IMPLEMENTATION.md)

- [ ] Individual object Lock/Unlock, shared road node editing mein bhi protection. [Idea](2026-10-16-object-focus-and-road-editing.md)

- [ ] NZ elevation data se slope aur terrain ka reliable site check. [Idea](2026-10-16-site-risk-and-facility-placement.md)
- [ ] Relevant NZ council flood maps aur doosre hazard sources ko connect aur verify karna.
- [ ] Water, steep land, protected areas aur land-use restrictions ko aik site view mein dikhana.
- [ ] Har analysis ke saath data source, date, coverage aur confidence saaf dikhana.
- [ ] Green/yellow/red/grey site suitability overlay, har colour ki wajah ke saath.
- [ ] Proposed entrance ko verified existing road tak check karna; sirf paas hone ko connection na samajhna.
- [ ] School, hospital, park aur worship facilities ke 2–3 locations rank karna.
- [ ] Facilities tak road/walking route ka waqt aur service coverage compare karna.
- [ ] Site options mein risk, access aur cost ke assumptions ke saath comparison.
- [ ] Market tools ke relevant features ki documented comparison aur source links.
- [ ] Realistic assets aur cinematic quality ko actual app screenshots aur performance se accept karna.

## Update karne ka tareeqa

Naya idea aaye to date wali file banayen aur yahan link add karen. Kaam verify hone ke baad checkbox tick karen. Agar sirf basic version bana hai to advanced kaam pending hi rakhen.
