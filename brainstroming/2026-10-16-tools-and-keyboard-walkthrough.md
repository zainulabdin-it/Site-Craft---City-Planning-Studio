# Tools ki jagah aur keyboard walkthrough

Date: 2026-10-16
Status: Implemented

## Masla

Layers panel band ho to cinematic controls tools ke upar aa rahe thay. Road aur Building bhi editing tools mein thay. Walkthrough ki keyboard movement chotay steps mein hoti thi.

## Ab kya hai?

- Cinematic controls toolbar se aagay rehte hain, taa ke tools nazar aayen.
- Road aur Building Asset Library ke All section mein hain. Search bhi kar sakte hain.
- Street ya Cinematic view mein WASD daba kar rakhne se continuous movement hoti hai.
- W/S aagay/peechay, A/D side par, arrows se dekhna aur Shift se tez chalna.
- Q/E se turn kar sakte hain. Drone mode mein Q/E height badalte hain.
- Key chhorne, window se focus hatne ya dialog khulne par movement rukti hai.
- Search/input mein typing se camera nahi chalta.
- Walking ke waqt upar/neeche dekhne se camera zameen mein nahi utarta; current height rehti hai.

Keyboard navigation ke liye Hand tool aur 3D, Street ya Cinematic view use karen.
