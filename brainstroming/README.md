# Brainstroming

Yahan Sitecraft ke naye ideas aur un ka status rakhen ge.

- Har idea ki file ka naam `YYYY-MM-DD-chota-sa-naam.md` hoga.
- Asan Roman Urdu mein likhen ge: masla kya hai, idea kya hai, aur user ko kya faida hoga.
- [IDEAS_CHECKLIST.md](IDEAS_CHECKLIST.md) sab ideas ki common list hai.
- `[x]` ka matlab kaam maujood hai aur check ho chuka hai. `[ ]` ka matlab abhi baqi hai.
- Agar kisi feature ka basic version bana hai, us ka advanced hissa alag pending item rahega.
- Naya idea aaye to dated file aur checklist dono update karen. Idea likhne ka matlab us ki implementation approve hona nahi hai.

Nayi file mein yeh cheezen likhen:

1. Idea aur date.
2. Abhi kya masla hai?
3. Hum kya banana chahte hain?
4. Chota sa example.
5. Kya bana hai aur kya baqi hai?
