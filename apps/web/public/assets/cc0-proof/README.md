# Realism proof assets

These lightweight models are used only for the first in-app visual proof.

- `park-tree-a.glb`, `park-tree-b.glb`, and `park-tree-c.glb`: Quaternius Stylized Nature MegaKit

All three models are CC0 1.0 and were already optimized for web delivery by the
Skyline Run project. The original Quaternius license is included beside them.

These are an intermediate quality gate. They are not described as photorealistic
assets; the full rollout must only happen after the in-app proof is reviewed.
